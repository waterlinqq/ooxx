# OOXX 戰棋

回合制戰棋，支援 **3×3** 與 **4×4** 棋盤，三戰兩勝，藍隊對戰 AI 紅隊。

## 啟動

**建議（開發用，含熱重載）：**

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本地網址（預設 http://localhost:5173）

**或使用 Python 靜態伺服器：**

```bash
python3 -m http.server 8080
```

瀏覽器開啟 http://localhost:8080（Three.js 透過 import map 從 CDN 載入）

正式版建置：

```bash
npm run build
npm run preview
```

## 技術

- 棋盤區使用 **Three.js** 等距低多邊形 3D 渲染（`js/board3d/`）
- 側欄、編隊、大廳維持原有 2D DOM UI
- 遊戲邏輯（`game.js`、`rules.js`、`ai.js`）完全不變

## 規則

- 開局棋盤為空，每回合可執行 **2 次行動**（部署 / 移動 / 攻擊），同一單位每回合只能行動一次
- 同隊連成整行（3×3 三子、4×4 四子；直、橫、斜），或全滅對手（棋盤與後備皆無單位），即贏得該局
- 先贏 2 局者贏得系列賽
- 先手：第 1 局藍隊先攻；第 2 局紅隊先攻；第 3 局由上一局落敗方先攻
- 每局結束完全重置棋盤與後備單位
- 藍紅兩隊使用固定 8 人編組（劍士×2、弓箭手×2、盾牌手、魔法師、刺客、炸彈兵），3×3 與 4×4 模式相同
