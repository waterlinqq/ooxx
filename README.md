# OOXX 戰棋

回合制戰棋，支援 **3×3** 與 **4×4** 棋盤，三戰兩勝，藍隊對戰 AI 紅隊。

## 啟動

```bash
python3 -m http.server 8080
```

瀏覽器開啟 http://localhost:8080

## 規則

- 開局棋盤為空，每回合可執行 **2 次行動**（部署 / 移動 / 攻擊），同一單位每回合只能行動一次
- 同隊連成整行（3×3 三子、4×4 四子；直、橫、斜），或全滅對手（棋盤與後備皆無單位），即贏得該局
- 先贏 2 局者贏得系列賽
- 先手：第 1 局藍隊先攻；第 2 局紅隊先攻；第 3 局由上一局落敗方先攻
- 每局結束完全重置棋盤與後備單位
