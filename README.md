# OOXX 戰棋

回合制戰棋，支援 **3×3**、**4×4** 與 **5×5**（2v2）棋盤，藍隊對戰 AI 紅隊。

## 啟動

**建議（開發用，含熱重載）：**

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本地網址（預設 http://localhost:5173）

**或使用 Python 靜態伺服器：**

```bash
python3 -m http.server 8080
```

瀏覽器開啟 http://localhost:8080（Three.js 透過 import map 從 CDN 載入）

正式版建置：

```bash
npm run build
npm run preview
```

## 技術

- 棋盤區使用 **Three.js** 等距低多邊形 3D 渲染（`js/board3d/`）
- 大廳、編隊、側欄維持原有 2D DOM UI
- 遊戲規則在 `js/rules.js`、流程在 `js/game.js`、AI 在 `js/ai/`

## 規則

- 開局棋盤為空，行動類型為部署 / 移動 / 攻擊 / 祝福，同一單位每回合只能行動一次
- 九宮格每回合 1 次行動、十六宮格 2 次；二十五宮格為 2v2，四個座位依 藍1 → 紅1 → 藍2 → 紅2 輪流，每個座位每次 1 個行動
- 同隊連成整行（3×3 三子、4×4 四子、5×5 五子；直、橫、斜），或全滅對手（棋盤與後備皆無單位），即獲勝
- 藍隊先攻
- 沒有固定編組：選好棋盤模式後進入編隊畫面，自由挑選要帶上場的職業（可重複），AI 紅隊則每局隨機編隊
- 每種模式有各自的編隊人數與同職業上限：九宮格 4 人／上限 2、十六宮格 10 人／上限 4、二十五宮格 14 人／上限 5

## 職業

| 職業 | HP | ATK | 特色 |
|------|-----|-----|------|
| 🏹 弓箭手 | 3 | 3 | 八方向射線、射程 3，只能打到每個方向上的第一個單位（友軍也會擋住視線） |
| 🛡️ 盾牌手 | 8 | 1 | 八向近戰，高生命值 |
| ⚔️ 劍士 | 5 | 3 | 八向近戰高傷害 |
| 🔮 魔法師 | 4 | 2 | 八方向光束，穿透該方向上所有敵方直到棋盤邊緣，不受射程限制 |
| 🗡️ 刺客 | 4 | 2 | 八向近戰，可跳躍至周遭兩格內的任意空格（可越過單位） |
| 💣 炸彈兵 | 3 | 2 | 八向近戰，被擊殺時自爆，對相鄰八格的敵方各造成 2 點傷害 |
| 🦅 老鷹 | 1 | 1 | 浮空八向近戰，只會受到弓箭與魔法攻擊 |
| ✨ 牧師 | 2 | 1 | 八向近戰；可輔助相鄰隊友，使其生命與攻擊各增加 1 |

所有角色都能沿八個方向攻擊；近戰角色可攻擊相鄰八格。

## AI

紅隊 AI 位於 `js/ai/`，介面是 `chooseAiAction(state, options)`：

- `board.js` — 搜尋用的盤面層：記憶化連線表、增量維護的連線計數、make/unmake 就地套用行動、Zobrist 雜湊
- `threat.js` — 攻擊威脅圖：每一格「敵方能造成的最大單次傷害」，用於落點安全與擋線單位脆弱度判斷
- `evaluate.js` — 零和靜態評估：材料（含後備）、連線完成所需行動數、位置權重、安全性
- `search.js` — 以「行動」為層的 alpha-beta negamax，含迭代加深、時間預算、置換表、走步排序與後備候選去重

難度可透過 `options.difficulty`（`easy` / `normal` / `hard`）調整，對應搜尋深度、時間預算與同分隨機程度。

### 對戰驗證

```bash
npm run sim -- --mode 4x4 --games 100                 # AI 自我對戰，結果輸出到 data/
npm run arena -- --mode 4x4 --games 20                # 目前 AI 對上 js/ai-legacy.js
npm run arena -- --mode 4x4 --roster random           # 每局隨機編組，貼近實際對局
npm run arena -- --mode 4x4 --b ../js/ai.js --difficulty-a hard --difficulty-b normal
```

兩者都接受 `--seed`，同一顆種子可完整重現一批對局。`arena` 會回報勝率、平均與最長決策時間、「落子後立即可被擊殺」比率，以及相異棋局數（用來確認 AI 不是每局都下同一套棋）。
