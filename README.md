# OOXX 戰棋

回合制戰棋，支援 **3×3** 與 **4×4** 棋盤，藍隊對戰 AI 紅隊。

## 啟動

**建議（開發用，含熱重載）：**

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本地網址（預設 http://localhost:5173）

**或使用 Python 靜態伺服器：**

```bash
python3 -m http.server 8080
```

瀏覽器開啟 http://localhost:8080（Three.js 透過 import map 從 CDN 載入）

正式版建置：

```bash
npm run build
npm run preview
```

## 技術

- 棋盤區使用 **Three.js** 等距低多邊形 3D 渲染（`js/board3d/`）
- 大廳、編隊、側欄維持原有 2D DOM UI
- 遊戲邏輯（`game.js`、`rules.js`、`ai.js`）完全不變

## 規則

- 開局棋盤為空，每回合可執行 **2 次行動**（部署 / 移動 / 攻擊），同一單位每回合只能行動一次
- 同隊連成整行（3×3 三子、4×4 四子；直、橫、斜），或全滅對手（棋盤與後備皆無單位），即獲勝
- 藍隊先攻
- 沒有固定編組：選好棋盤模式後進入編隊畫面，自由挑選要帶上場的職業（可重複），AI 紅隊則每局隨機編隊
- 每種模式有各自的編隊人數與同職業上限：九宮格 4 人／上限 2、十六宮格 10 人／上限 4、二十五宮格 14 人／上限 5
